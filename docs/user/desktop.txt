帧场 AE 工作台 V1.1.0 · Windows 桌面便携版

启动
1. 解压整个压缩包到可写目录，双击“帧场AE工作台.exe”。直接打开独立程序窗口，不打开浏览器。
2. 不要单独移动 EXE，必须保留 _internal 文件夹。无需安装 Python 或 FFmpeg。
3. 若提示缺少 WebView2，运行 runtime-installers 中的微软官方 x64 离线安装器，安装完成后重新打开工作台。不要在已具备组件的电脑上重复安装。
4. 支持 Windows 10/11 x64；桌面组件要求 .NET Framework 4.8。Windows 10 较旧系统需通过微软官方渠道更新组件。

使用
导入工程文件夹 → 扫描工程 → 添加替换候选 → 生成并预览组合计划 → 选择数量导出。
单张图片可以直接选文件；序列帧选择文件夹。同一个素材可追加多个候选。
视频规格在“视频导出设置”修改。导出记录、生图/视频历史支持折叠和分页。
AI 生图/生视频需要在“AI 生成设置”填写自己的火山方舟 API 配置与密钥。
本包不含账号、密钥、用户工程、素材、候选或历史导出记录。

关闭与重开
窗口右上角 × 或“退出工作台”都会关闭程序及其本地后台。
有扫描、导出、AI 生成或文件夹选择未结束时，会阻止关闭。请等待完成或使用任务自身的停止操作。
重复双击会回到同一工作区的现有窗口。默认只监听本机，不对公网开放。
开发版或旧版占用 8518 时桌面版自动使用其他空闲端口；不要同时让两个版本扫描/渲染 AE。

AE 要求
本机必须安装并可正常运行 After Effects（主要验证 AE 2022），以及工程所需插件、字体和素材。
先在 AE 正常打开工程，保存现有改动；首选项中允许脚本写入文件。
没有 AE 仍能打开工作台及环境设置，但不能完成依赖 AE 的扫描、合成预览、工程生成及渲染。
本包不含 Adobe After Effects，不自动补齐工程缺失素材。原始 AEP 与素材不会被改写。
新电脑建议先导出一份检查，再批量导出。

数据
data-v1 保存工作区、预览与日志；outputs 保存新工程和视频。
若程序目录不可写，将使用 %LOCALAPPDATA%\FrameWorkbench；实际位置见“环境设置”。
发布包为全新工作区。需要保留旧便携版记录时，先关闭两版程序，再复制旧 data-v1 和 outputs 到新版目录。
源码版 data-v02 与桌面版 data-v1 独立；不自动复制，避免混用工作区。
历史工程及素材为绝对路径，换电脑后可能需要重新导入/链接。
API 密钥受 Windows 当前用户加密保护，换电脑需重新填写。
输出 AEP 可能依赖原素材和 outputs 内 adapted 文件夹，不是 AE“收集文件”后的完整工程包。

排错
启动日志：data-v1\launcher.log。渲染日志在对应输出目录。
本程序未进行代码签名；请核对发布包 SHA-256，不要关闭系统防护。
微软离线安装器具有 Microsoft Corporation 有效数字签名。
第三方组件许可和来源见 _internal\licenses。
